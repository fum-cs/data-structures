## Course Overview

The course develops students' ability to solve computational problems efficiently and to reason about the theoretical foundations of data structures. Students study how to analyze running time and memory usage, compare the advantages and limitations of alternative data structures, and select suitable structures for a given problem.

Mathematical analysis is an important part of the course. Students will work with asymptotic notation, recurrence relations, inductive arguments, and techniques for analyzing algorithmic performance. The course also emphasizes implementation, problem solving, and the relationship between theoretical properties and practical use.

## Learning Outcomes

By the end of the course, students should be able to:

- Analyze algorithm running times using growth functions and asymptotic notation.
- Solve recurrence relations using substitution, recursion trees, and the Master Theorem.
- Implement and use linear data structures, including arrays, singly linked lists, doubly linked lists, circular linked lists, stacks, queues, and deques.
- Apply linear data structures to problems such as expression processing and memory management, including garbage collection.
- Explain general tree concepts, tree representations, structural induction, expression trees, and tree traversal methods.
- Implement binary search trees and balanced search trees, including AVL trees.
- Analyze hash tables and hash functions, and apply chaining, open addressing, and universal hashing.
- Analyze and compare sorting algorithms, including Heapsort, Quicksort, Counting Sort, and Radix Sort.
- Explain lower bounds for comparison sorting and use decision trees to reason about them.
- Apply advanced data structures, including Red-Black Trees, order-statistic trees, interval trees, B-Trees, and disjoint-set structures, to more complex computational problems.
- Evaluate data structures in terms of their time and space costs and choose appropriate structures for specific tasks.

## Teaching Approach

The course combines conceptual instruction with mathematical analysis and practical problem solving. Teaching activities may include:

- Explanations and derivations using the board and/or slides.
- In-class questions and discussion to check understanding.
- Problem-solving activities and short quizzes.
- Regular problem-solving sessions focused on challenging topics such as recurrences, inductive proofs, and asymptotic analysis.
- Written assignments and implementation assignments.

## Student Responsibilities

Students are expected to:

- Participate actively in class discussions and attempt in-class problems.
- Take part in short in-class quizzes.
- Complete and submit written and programming assignments.
- Attend and take the midterm and final examinations.
- Review lecture materials and practice solving problems independently.
